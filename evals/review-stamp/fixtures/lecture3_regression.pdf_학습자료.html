0. 기본 용어
모델

입력 x를 받아 예측 y를 내는 계산식.

예x = 3 → y = 7

가중치

입력에 곱하는 숫자. 직선의 기울기.

예w = 2

손실

예측이 정답에서 얼마나 틀렸는지 재는 숫자.

예예측 7, 정답 8 → 틀린 양 1

1. 개념 설명

1.1 모델과 예측

Model은 x에 weight w를 곱하고 b를 더해 y를 예측한다. 식으로는 y = w·x + b다. p.1

  • w 직선의 기울기. x가 1 커질 때 y가 얼마나 커지는지.
  • b 직선이 세로축과 만나는 높이(intercept).
예시 ① w와 b가 정해지면 예측은 계산 한 줄이다
이 예시로 알 수 있는 것

Model은 숫자 두 개(w, b)로 정해진다.

예시

w = 2, b = 1, x = 3 → y = 2 × 3 + 1 = 7 p.1

해설
  • 곱하기 2 × 3 = 6. 기울기가 2라 x 한 칸에 y가 2씩 오른다.
  • 더하기 6 + 1 = 7. b는 출발 높이다.

1.2 Loss와 gradient descent

Loss는 예측과 정답의 차이를 제곱해 평균 낸 값이다. MSE = (1/n) Σi (yi − ŷi)2 p.1

w는 w ← w − lr · ∂L/∂w 로 조금씩 고친다. lr이 너무 크면 발산하고 너무 작으면 느리다. p.2

2. 원자료 해설

We update w by w <- w - lr * dL/dw.w를 w − lr × dL/dw 로 갱신한다.

lecture3_regression.pdf p.2

  • lr learning rate. 한 번에 얼마나 움직일지.
  • dL/dw w를 늘리면 Loss가 얼마나 늘어나는지. 그 반대 방향으로 간다.

3. 핵심 요약

  • Model y = w·x + b. 숫자 두 개가 전부다.
  • Loss 틀린 양의 제곱 평균(MSE).
  • Gradient descent Loss가 줄어드는 방향으로 w를 lr만큼씩 옮긴다.
