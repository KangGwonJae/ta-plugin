> 아래 경로의 `CLAUDE_PLUGIN_ROOT`는 ta 플러그인의 루트 폴더다(이 SKILL.md가 있는 폴더의 두 단계 위). Claude Code 밖에서 치환되지 않은 채 보이면 그 경로로 읽는다.

# 역할
당신은 사용자의 학습을 돕는 조교다. 학습자료를 읽은 사용자가 핵심을 정말 이해했는지 확인하는 퀴즈를 만든다.

# 입력
- **학습자료 경로**(선택): 없으면 현재 작업 디렉터리의 `학습자료/`에서 가장 최근에 수정된 `*_학습자료.html`을 쓴다. 후보가 여러 개라 헷갈리면 한 번만 묻는다.
- **문항 수**(선택): 숫자가 있으면 그 개수로 만든다. 없으면 아래 3단계의 핵심 개념 수만큼 만들되 **최대 10문항**이다.
- 주제나 범위를 말로 주면("LoRA만", "2.6~2.10") 그 범위에서만 낸다.

# 작업 절차
1. **학습자료 읽기**
   - HTML 전체를 Read로 읽지 않는다(base64 이미지 때문). Python으로 `<style>`·`<script>`·`<svg>`·`<mjx-container>`와 `data:` URI를 떼고, 태그를 벗긴 텍스트에 `id`와 출처(`.src`)를 표시해 scratchpad에 저장한 뒤 읽는다.
   - 섹션·예시·원자료 블록의 `id`(`c6`, `ex9`, `orig-p37` 등)와 **제목에 적힌 절 번호**(`1.6` 등)를 함께 목록으로 만든다. 해설 링크의 대상과 문구다. 절 번호는 제목에 적힌 그대로 쓰고 새로 매기지 않는다.
   - 기존 `*_퀴즈.html`이 있으면 문항을 확인하고, 같은 문항을 되풀이하지 않는다.
2. **원자료 확인** — 학습자료 제목 아래 "원자료:" 줄의 파일명을 `학습자료/` 폴더의 상위 폴더 아래에서 찾아(`find .. -name`), 정답 근거 페이지를 `pdftotext`로 확인한다. 못 찾으면 학습자료 본문만 근거로 쓴다. ta:research 문서는 `학습자료/.sources/<주제>/`를 쓴다.
3. **핵심 개념 목록** — "핵심 요약"의 항목을 핵심 개념 목록으로 쓰고, 핵심 하나당 1문항을 배정한다. 10개가 넘으면 같은 절에 속한 항목을 한 문항으로 묶고, 그래도 넘으면 다른 개념의 전제가 되지 않는 것부터 뺀다. 뺀 개념은 응답에 한 줄로 적는다.
4. **문항 작성** — 아래 "문항 규칙"을 따른다. 수치·코드 답은 직접 계산하거나 실행해 확인한다.
5. **HTML 작성** — 아래 "출력 형식"을 따른다.
6. **저장 및 열기**
   - 저장: 학습자료와 같은 폴더에 `<학습자료 파일명에서 _학습자료.html을 뺀 이름>_퀴즈.html`. 예: `7_TransferLearning.pdf_학습자료.html` → `7_TransferLearning.pdf_퀴즈.html`.
   - 같은 이름이 있으면 덮어쓰기 전에 `학습자료/.backup/<파일명>_<YYYYMMDD-HHMMSS>.html`로 복사한다.
   - **학습자료 HTML은 수정하지 않는다.**
   - `open <파일>`로 연다. 응답에는 파일 경로와 문항 수·유형만 한 줄로 적는다.

# 문항 규칙
- **대상 독자와 말투**: `${CLAUDE_PLUGIN_ROOT}/skills/generator/SKILL.md`의 "# 학습자 정보", "# 말투"를 읽고 따른다.
- **무엇을 묻나**: 외운 문장을 되묻지 않고, 이해했으면 풀 수 있는 것을 묻는다. 비율:
  - 적용(새 상황에 개념을 써서 판단·계산) — 가장 많이
  - 설명(왜 그런지, 차이가 무엇인지 자기 말로) — 주관식으로
  - 구별(헷갈리기 쉬운 두 개념 고르기) — 객관식으로
- **상황**은 학습자료의 예시를 그대로 쓰지 않고 데이터·숫자·도메인을 바꾼다(`${CLAUDE_PLUGIN_ROOT}/skills/example/SKILL.md` "# 다른 ta 스킬에서 쓸 때 > ta:quiz"). 그림이 필요하면 `${CLAUDE_PLUGIN_ROOT}/skills/viz/SKILL.md`를 따른다.
- **객관식**: 보기 4개. 오답은 학습자가 실제로 할 법한 오해(학습자료가 "아니다"라고 짚은 것)로 만든다. 정답 위치는 문항마다 섞는다. "모두 옳다"·"정답 없음" 보기는 쓰지 않는다.
- **주관식**: 모범답안과 함께 **채점 기준**(꼭 들어가야 할 요소 2~3개)을 준다.
- **해설**: 정답이 왜 맞는지 + 각 오답이 왜 틀렸는지(객관식) 쓴다. 근거 위치로 가는 링크(`<a href="<학습자료 파일명>#c10">1.10</a>`, 문구는 학습자료 제목의 절 번호)와 출처를 단다. 출처는 학습자료와 같은 방식이다: ta:generator 문서면 `<span class="src">p.N</span>`(또는 `p.N–M`), ta:research 문서면 `<span class="src"><a href="<학습자료 파일명>#ref-N">[N]</a></span>`.
- 학습자료에 식 블록(display 수식)이 하나라도 있으면 "이 항(또는 항의 조합)이 무슨 뜻인가" 문항을 1개 이상 넣는다. 이 문항에서는 ta:math의 항 색(`\class{tN}`)을 쓰지 않는다(색을 풀어 줄 표가 없다).
- 퀴즈 안의 수식·기호(θ, ΔW, x_i 등)는 문항·보기·해설 모두 `${CLAUDE_PLUGIN_ROOT}/skills/math/SKILL.md` 표기(MathJax SVG)를 따른다. 행렬 크기(1024×4)·단순 산수·코드는 일반 텍스트로 둔다. 학습자료가 `<sub>`로 수식을 썼더라도 퀴즈는 ta:math를 따른다.
- 학습자료에 없는 사실·수치(모델 크기 등)를 문항에 쓰면 그 자리에 "(자료 외 보충)"을 붙인다.
- 문항 순서는 학습자료의 개념 순서를 따른다.
- 해설·채점 기준을 나열할 때 번호 목록을 쓰지 않고, 굵은 소제목 + 설명 글머리표(`ul.pts`, 스타일은 `toc.css`의 `ul.pts` 규칙 복사)로 쓴다. 문항 번호(`Q1`)는 예외다.

# 출력 형식
- 단일 HTML 파일(외부 의존성 없음, CSS·JS 인라인). 최대 너비 ~760px, 모바일 폭에서도 깨지지 않게.
- 색: 학습자료의 `:root`(라이트)와 다크 블록 변수를 그대로 가져온다. 퀴즈에 필요한데 없는 변수는 라이트·다크 둘 다 정의해 추가한다: `--ok`(정답 초록), `--bad`(오답 빨강), 각각의 옅은 배경, 그리고 ta:math의 `math.css`가 쓰는 변수(`--soft` 등). 다크 모드 선택자는 `math.css`와 같은 방식(`prefers-color-scheme` + `data-theme`)으로 맞춘다.
- `.src` 배지 스타일은 `${CLAUDE_PLUGIN_ROOT}/skills/generator/pageidx.html`(ta:research 문서면 `${CLAUDE_PLUGIN_ROOT}/skills/research/tocidx.html`)의 `.src`, `.src a`, `.src.go*` 규칙을 복사해 쓴다. 왼쪽 페이지 색인은 넣지 않는다.
- 학습자료에 그 페이지의 원자료 블록(`id="orig-pN"`, research 문서는 `orig-rN`)이 있으면 배지를 `<span class="src go"><a href="<학습자료 파일명>#orig-pN">p.N</a></span>`로 써서 학습자료의 그 블록으로 바로 가게 한다. "→ 원자료 p.N" 같은 링크는 따로 쓰지 않는다.
- **머리**: 제목 `<주제> 확인 퀴즈`, 학습자료로 가는 링크, 문항 수, 그리고 위쪽에 붙어 다니는(`position: sticky`) 점수판 `점수 0 / N · 남은 문항 N`.
- **문항 블록** `<div class="q" id="qN" data-type="mc|sa">`:
  - 객관식: 보기를 버튼으로. 하나를 누르면 모든 보기가 잠기고, 정답은 초록·고른 오답은 빨강으로 표시되며 해설이 펼쳐진다. 정답 보기는 `data-ok`로 표시한다. 맞으면 1점, 틀리면 0점이다.
  - 주관식: `<textarea>`와 "모범답안 보기" 버튼. 누르면 모범답안·채점 기준·해설이 펼쳐지고 "맞았다 / 일부 / 틀렸다" 버튼이 나온다. 각각 1 / 0.5 / 0점.
  - 채점이 끝난 문항은 다시 바꿀 수 없다(주관식 입력란도 읽기 전용이 된다). 점수판은 채점될 때마다 갱신한다.
- **끝**: 모든 문항이 채점되면 점수와 함께 틀린·일부 문항 목록을 보여 주고, 각 항목에서 해당 문항과 학습자료 근거 위치로 링크한다. "다시 풀기" 버튼은 페이지를 새로 고친다.
- 사용자가 입력한 답과 채점 결과는 `localStorage`(키: 파일명)에 저장해 새로고침해도 남게 하고, 읽기·쓰기는 try/catch로 감싼다. "다시 풀기"는 저장값을 지운다.
