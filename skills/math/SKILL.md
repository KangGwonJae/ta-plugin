> 아래 경로의 `CLAUDE_PLUGIN_ROOT`는 ta 플러그인의 루트 폴더다(이 SKILL.md가 있는 폴더의 두 단계 위). Claude Code 밖에서 치환되지 않은 채 보이면 그 경로로 읽는다.

# 역할
수식을 교과서처럼 보이게 넣고, 독자가 식을 **말로 읽을 수 있게** 만든다. 식을 보여 주는 것만으로는 부족하다. 식의 각 조각이 무엇을 세거나 재는지, 조각들이 합쳐지면 무슨 뜻이 되는지를 차례로 쌓아 올려 설명한다.

대상 독자는 `${CLAUDE_PLUGIN_ROOT}/skills/generator/SKILL.md`의 `# 학습자 정보`, 말투는 같은 파일의 `# 말투`를 따른다.

# 무엇이 수식인가
- 수식으로 쓴다: 첨자·위첨자가 붙은 기호(λ_p, a_ip, x²), Σ·∏·분수·루트, 부등식·등식 관계, 함수식(f(x), max, min), 벡터·행렬 표기. 문장 속에 혼자 나오는 기호도 포함한다.
- 수식으로 쓰지 않는다: 문장 속 단순 숫자 계산(1200 + 1100 = 2300), 단위, 코드. 이것들은 일반 텍스트나 `<code>`로 둔다.

# 표기 규칙
1. **LaTeX로 쓰고 MathJax SVG로 변환한다.** HTML `<sub>`/`<sup>`, 유니코드 Σ·λ·≤, monospace 정렬로 수식을 흉내 내지 않는다. SVG를 손으로 쓰지 않는다.
   ```bash
   T="${CLAUDE_PLUGIN_ROOT}/skills/math/tex2svg.js"
   node "$T" '\lambda_p'                                  # 문장 속(inline)
   node "$T" --display '\sum_{p} a_{ip}\,\lambda_p \ge b_i'  # 단독 줄(display)
   printf '%s' '[{"tex":"a_{ip}"},{"tex":"\\sum_p \\lambda_p","display":true}]' | node "$T" --json  # 여러 개
   ```
   - 결과는 `<span class="m" data-tex="…" role="img" aria-label="…"><svg>…</svg></span>`. 글자색이 `currentColor`라 라이트/다크 모드를 따라간다.
   - LaTeX에 오류가 있으면 exit 1과 한 줄 오류를 낸다. 고쳐서 다시 돌린다.
   - 여러 개를 JSON으로 넘길 때 셸 `echo`를 쓰지 않는다(zsh가 `\f` 등을 제어문자로 바꾼다). `printf '%s'`나 Python `subprocess`로 넘긴다.
   - MathJax가 없으면(`node_modules` 없음) `cd "${CLAUDE_PLUGIN_ROOT}" && npm install`(플러그인 루트에 package.json이 있다).
2. **한국어는 수식 밖에 둔다.** `\text{한글}`은 쓰지 않는다. 라벨·설명은 옆 HTML 칸에 쓴다.
3. **Σ의 범위는 아래에 단다.** display에서는 기본으로, 표 칸 안에서는 `\displaystyle`를 붙인다. 곱셈 기호가 생략된 곱은 `\,`로 살짝 띄운다(`a_{ip}\,\lambda_p`).
4. **여러 줄 모형**(목적식 + 제약식들)은 3열 그리드로 쓴다: 라벨 | 수식 | 한 줄 뜻.
   ```html
   <div class="tldr eq" role="group" aria-label="모형 이름">
   <div class="eq-lab">최소화</div><div class="eq-m">{SVG}</div><div class="eq-d">쓰는 롤 수</div>
   ...
   </div>
   ```
5. **CSS는 한 번만 넣는다.** 문서에 `/*ta-math:start*/`가 없으면 `${CLAUDE_PLUGIN_ROOT}/skills/math/math.css` 내용을 `</style>` 바로 앞에 넣는다.
6. **색으로 항 짝짓기.** 식 안의 항을 `\class{t1}{…}`~`\class{t5}{…}`로 감싸고, 설명 표에서 그 항의 행에 같은 `class="t1"`을 단다. 그러면 식의 항과 표의 행이 같은 색으로 이어진다.
   - 한 식에 최대 5색. 색만으로 구분하지 않는다. 표 첫 칸에 그 부분식 SVG를 함께 둔다.
   - `\class`는 같은 식의 첫 등장(display)에만 쓴다. 문장 속 inline 기호에는 색을 넣지 않는다.

# 설명 규칙
수식 하나를 이 순서로 설명한다. 짧은 inline 기호는 ①과 ③의 기호 행만 쓴다.

**① 먼저 말로** — 식 바로 앞에 이 식이 무엇을 구하거나 무엇을 제한하는지 한 문장으로 적는다. 독자가 식을 보기 전에 무엇을 찾아야 하는지 안다.

**② 식** — display 수식. 항마다 `\class{tN}`으로 색을 단다.

**③ 식 뜯어보기 표** — 각 기호 → 기호를 묶은 항 → 항의 조합 → 관계·목표 순서로, **안쪽에서 바깥쪽으로** 쌓는다.
```html
<table class="eqx">
<tr><th>부분</th><th>뜻</th><th>예시 ①에서</th></tr>
<tr class="t2"><td>{a_ip SVG}</td><td>pattern p 하나에 폭 i 조각이 몇 개 들어가는지 (개)</td><td>"1200·1200·1100"의 폭 1200 → 2</td></tr>
<tr class="t3"><td>{λ_p SVG}</td><td>pattern p로 자르는 롤 수 (롤)</td><td>2</td></tr>
<tr class="combo t2"><td>{a_ip λ_p SVG}</td><td>pattern p로 자른 롤들에서 나오는 폭 i 조각 총수 (개). "롤당 개수 × 롤 수"</td><td>2 × 2 = 4</td></tr>
<tr class="combo t1"><td>{Σ_p a_ip λ_p SVG}</td><td>모든 pattern에서 나온 폭 i 조각을 다 더한 것</td><td>4 + 0 = 4</td></tr>
<tr class="combo"><td>{… ≥ b_i SVG}</td><td>그 합이 주문량 이상이어야 한다</td><td>4 ≥ 4 ✓</td></tr>
</table>
```
- 열은 **부분 | 뜻 | 예시 값**. 예시 값은 문서에 이미 있는 예시(가능하면 같은 숫자)로 채운다. 문서에 예시가 없으면 손으로 따라 할 수 있는 작은 숫자를 새로 정한다.
- **뜻 칸에는 무엇을 세는지와 단위를 적는다**(개, 롤, mm, 원, 확률). "계수", "변수"처럼 역할 이름만 적지 않는다.
- **조합 행**(`class="combo"`)이 이 스킬의 핵심이다. 두 항이 곱해지거나 더해지거나 묶이면, 합쳐진 결과가 무엇인지 새 문장으로 적는다. 연산은 이렇게 읽는다.
  - 곱 → "~당 ~ × ~개 = 총 ~" (단위가 어떻게 바뀌는지 보인다)
  - Σ_k → "k를 하나씩 바꿔 가며 전부 더한다". 무엇을 따라 더하는지(k가 무엇의 번호인지) 적는다.
  - 분수 → "~당 ~", "~ 중 ~의 비율"
  - ≥, ≤, = → "적어도", "넘지 않게", "딱 같게". 왜 그 방향인지 한마디 붙인다(주문은 모자라면 안 되니까 ≥).
  - min/max → "이 값을 가장 작게(크게) 만드는 ~을 고른다". 무엇을 골라서 무엇을 줄이는지 구분한다.
  - 첨자가 식 밖에 남으면(예: Σ_p 뒤에 i가 남음) → "i마다 이런 식이 하나씩 있다(모든 폭에 대해)".
- 앞 행에서 풀지 않은 기호를 뒤 행에서 쓰지 않는다.
- 독자가 처음 보는 연산 기호(Σ, ∏, ∈, ∀, ‖·‖ 등)는 문서에서 처음 나올 때 기호 행 하나로 읽는 법을 적는다.

**④ 숫자 대입** — `<div class="eqcalc">`에 문서 예시 숫자를 식에 그대로 넣어 한 줄씩 계산한다. 계산은 직접 해서 맞는지 확인한다. ③의 예시 값 칸으로 충분히 보이면 생략한다.

**⑤ 다시 읽기** — `<p class="eq-say">`에 식 전체를 한국어 한 문장으로 다시 읽는다. 기호를 쓰지 않고, ③에서 쌓은 뜻을 이어 붙인다.
> 예: "모든 pattern에서 나오는 폭 i 조각을 다 더하면, 그 폭의 주문량 이상이어야 한다. 이 조건이 폭마다 하나씩 있다."

**⑥ 왜 이 모양인지 (선택)** — 모양을 바꾸면 무엇이 달라지는지 보여 주는 것이 이해에 도움이 될 때만 쓴다(≥를 =로 바꾸면 정확히 맞는 조합이 없을 때 풀 수 없다 등).

## 여러 식이 모인 모형
- 먼저 4번 그리드로 모형 전체를 보여 준다.
- 그다음 줄마다 ③~⑤를 쓴다. 앞 줄에서 이미 푼 기호는 다시 행을 만들지 않고 그 표로 링크(`#eqx-N`)한다.
- 표·계산 블록에 `id="eqx-N"`을 붙여 본문에서 상호 참조할 수 있게 한다.

## 같은 기호가 다시 나올 때
- 처음 나온 곳에서만 풀이한다. 이후에는 inline SVG만 쓰고, 멀리 떨어져 있으면 처음 푼 표로 링크한다.

## 퀴즈 (ta:quiz)
- 수식이 문서의 핵심이면 퀴즈 중 최소 1문항은 "이 항(또는 항의 조합)이 무슨 뜻인가"를 묻는다.

# 다른 ta 스킬에서 쓸 때
- **ta:generator·ta:research**: 본문을 쓸 때 위 표기·설명 규칙을 그대로 쓴다. 출처 표기(`.src`)는 식 블록이나 뜯어보기 표 바로 뒤 문장 끝에 단다.
- **supplement**: 보충에서 새 수식을 꺼내지 않는 원칙은 그대로다. 단, 막힌 부분이 수식이면 그 식을 inline·display SVG로 다시 보여 주고 ③~⑤를 **막힌 항 위주로** 쓴다. 숫자 대입(④)을 꼭 넣는다.
- **example**(ta:example 규칙으로 쓰는 모든 예시): 예시에 식 대입이 들어가면 ④ 형식으로 쓰고, 예시 값을 바꾼 ③ 표를 짧게 붙여도 된다.
- **quiz**: 문항·보기·해설의 수식은 위 표기 규칙(SVG)을 따르되 `\class{tN}` 색은 쓰지 않는다("## 퀴즈" 참고).

# 직접 호출했을 때 (기존 학습자료 수식 고치기)
1. **대상 파일**: 인자 경로. 없으면 현재 작업 디렉터리의 `학습자료/`에서 가장 최근 수정된 `.html`. 그것도 없으면 묻는다.
2. **수식 찾기**: HTML 전체를 Read로 읽지 않는다(base64 이미지 때문). Python으로 아래 후보를 찾는다.
   - `<sub>`/`<sup>`가 붙은 기호, 유니코드 수식 문자(Σ ∑ ∏ √ ≤ ≥ ≠ ≈ ∈ ∀ λ μ σ θ π 등), monospace 스타일로 정렬한 식 블록.
   - 이미 `class="m"`인 SVG는 건너뛴다.
   - 사용자가 수식이나 위치를 지정했으면 그것만 고친다.
3. **백업**: `<파일이 있는 폴더>/.backup/<파일명>_<YYYYMMDD-HHMMSS>.html`.
4. **변환**: 수식을 LaTeX로 옮겨 SVG로 바꾼다. 원래 뜻을 바꾸지 않는다. 식 블록은 display나 그리드로, 문장 속 기호는 inline으로 바꾼다.
5. **설명 보강**: 각 display 식에 위 설명 규칙(①~⑤) 중 빠진 것을 덧붙인다. 원래 문장은 지우지 않는다. 근거·출처 표기는 그 문서를 만든 스킬의 방식(`파일명 p.N` 또는 `[N]`)을 따른다.
6. **확인**: 아래 "작성 후 점검"을 하고, `open`으로 연다. 응답에는 파일 경로, 바꾼 수식 개수, 덧붙인 설명 블록만 적는다.

# 작성 후 점검
- 문서에 `<sub>`·유니코드로 흉내 낸 수식이 남아 있지 않은지 확인한다(단위나 화학식 같은 비수식 첨자는 제외).
- 수식 부분만 잘라 헤드리스 Chrome으로 라이트·다크 두 번 캡처해 직접 본다. 다크는 미리보기 HTML의 `<html>`에 `data-theme="dark"`를 붙여 찍는다. 아래 경로는 macOS 기준이다. 다른 OS면 그 OS의 Chrome 경로를 쓰고, Chrome이 없으면 이 캡처는 건너뛴다.
  ```bash
  "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --disable-gpu \
    --window-size=820,600 --screenshot=<scratchpad>/eq.png "file://<scratchpad>/eqprev.html"
  ```
  - 볼 것: 글자 겹침·잘림, 색 짝짓기가 맞는지, 표 첫 칸 수식 크기, 모바일 폭(`--window-size=400,…`)에서 가로 넘침.
- ③ 표의 예시 값과 ④ 계산을 다시 계산해 맞는지 확인한다.
